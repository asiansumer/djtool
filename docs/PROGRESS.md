## 2026-09-23 · 本地曲库第一版可试用

本轮按用户确认的浅色双栏方向实现真实本地工作台。分工已改为助手实现、用户试用反馈；后续再解释原理，不再把功能留为学习练习。

### 当前可用

- 选择 MP3 / 文件夹、后台复制到独立曲库、读取真实标签和封面、按内容去重；保留源文件。
- SQLite 保存歌曲、分组、Set、顺序、歌曲备注与各 Set 内独立的衔接备注。
- 待整理、曲库、分组与 Set 页面；搜索艺人 / 歌名 / 文件名，筛选风格和 BPM。
- 整理标题、艺人、风格、阶段、能量与人工 BPM；标签 BPM 和人工值明确区分。
- 从曲库拖入当前 Set、拖动排序、移除并撤销；删除 Set / 分组不删除音频。
- Qt Multimedia 试听、暂停、跳转、音量、前后曲、Finder 定位。
- 空曲库引导、缺失文件提示、导入错误汇总、停止导入与导入中关闭保护。
