## 现在可先试用的部分

打开 `dist/DJTOOL.app`，新建或选择自己的 DJTOOL 曲库（升级前自动备份数据库）。不要同时运行旧代码窗口和新 App 管理同一个曲库。

1. 左侧“订阅与自动接收” → “接收本地目录”，选一个包含少量已下载 MP3 / NCM 的目录。
2. 观察 15～30 秒；文件稳定后进入待整理，源文件保留。转换失败可查看来源提示并重试。
3. 查看元数据，确认标题、艺人、封面、时长；App 不再分析或校正 BPM。
4. 建一个 Set，调整顺序和衔接备注，关闭重开检查保存。
5. “导出与同步” → “导出 Set”，查看选曲单与备注。

用户已解除此前的播放限制，可以正常试听。发布包自检仍使用合成音频，不替代真实听感验收。

网易云入口：“链接收歌” → “网易云接入设置”。默认本机开源入口无需开发者 Key；普通会员会话需在隐藏输入框配置并通过验证，不能使用原官方 accessToken 代替。
